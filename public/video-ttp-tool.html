❌ 既存ツールのアプローチ（精度が低い）
  • ✗テキストの「文字列一致」だけで判定
  • ✗1文・1センテンス単位で細かくマッチング
  • ✗前後の文脈を考慮しない
  • ✗重複・矛盾のチェックなし
  • ✗「使われていない箇所」の除外できない
✅ 改善アプローチ（精度が高い）
  • ✓文の「意味・文脈」で類似度を計算
  • ✓近い箇所は自動でひとつのまとまりに統合
  • ✓前後の文脈も含めて評価
  • ✓重複・重なりを自動除去
  • ✓信頼スコアで低精度ヒットを除外

入力と出力

INPUT（入力するもの）
  • 参考動画URL（構成・順番の参照元）
  • 素材動画URL（実際に使う映像）
  • 複製回避素材①URL＋タイムスタンプリスト
  • 複製回避素材②URL＋タイムスタンプ
→
OUTPUT（出力されるもの）
  • 完成動画ファイル（MP4）
  • 波音リツのナレーション差し替え済み
  • 複製回避クリップ挿入済み
  • マッチング結果レポート（確認用）

処理の流れ

1

📥 動画ダウンロード ● 完全自動

参考動画・素材動画・複製回避素材を全URLから自動取得。

yt-dlp
2

📝 両動画を高精度文字起こし ● 完全自動

参考動画・素材動画の両方を、単語レベルの時刻情報付きで文字起こし。

OpenAI Whisper
3

🧠 意味マッチング（AIの核心処理） ● 完全自動

テキスト一致ではなく「意味・文脈の類似度」で参考動画と素材動画の対応箇所を特定。近い箇所は自動でひとまとまりに統合し、重複・低精度ヒットを除去。

OpenAI Embeddings セマンティック類似度 重複除去アルゴリズム
4

👁️ マッチング結果の確認 ◐ 軽確認（AIが候補提示）

AIが出したタイムスタンプ候補と信頼スコアをリスト表示。目視確認は最小限で、OKを押せば次工程へ。

5

🗣️ ナレーション音声合成 ● 完全自動

参考動画のスクリプトをもとに、波音リツの音声を自動生成して差し替え。

VOICEVOX（波音リツ） CoeFont API
6

✂️ クリップカット＆結合 ● 完全自動

素材動画からマッチ箇所をカット → ナレーション差し替え → 複製回避素材をまとめ直前に挿入 → 最終動画として書き出し。

ffmpeg
✓

🎬 完成動画ファイル出力

MP4ファイルとして書き出し完了。
