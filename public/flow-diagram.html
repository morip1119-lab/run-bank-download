ネット銀行 CSV 自動ダウンロード＆アップロード

処理フロー図解 — npm run sumishin-download を実行したとき何が起きるか

処理の流れ

START

コマンド実行

ターミナルで npm run sumishin-download を入力
→ node scripts/download_sumishin_csv.js が起動

STEP 1

🔑 ログイン

Playwright（ブラウザ自動操作）が Chromium を起動し
.env に書いた ID・パスワードを自動入力してログイン

STEP 2

📄 入出金明細ページへ移動

メニューの「入出金明細」リンクを自動クリックして移動

STEP 3　×11回繰り返し

💾 各口座のCSVをダウンロード

1
口座を選択　ドロップダウンメニューを自動操作（代表口座 → 税金 → … の順）
2
前月へ移動　ページ内の「3月 入金… 出金…」リンクをクリックして対象月に切り替え
3
ダウンロードボタンを自動クリック → パネルが開く → 「CSV」ボタンを自動クリック
4
APIレスポンスをキャプチャ　銀行APIが JSON 形式でCSVデータを返す
→ Java byte配列 → Shift-JIS → CSVファイルに変換
5
ファイル保存　downloads/2026-03/202603_代表口座.csv など
STEP 4

☁️ Google Drive へ自動アップロード

token.json の認証情報で Google Drive API に接続
→ 指定フォルダ内に 「2026年3月」 サブフォルダを自動作成
→ 11個のCSVファイルをまとめてアップロード

DONE

✅ 完了

ターミナルに結果サマリーが表示される
Google Drive のフォルダURLも表示されるので確認可能

登場人物と役割

⚙️
Node.js
スクリプトを動かすエンジン。「車のエンジン」に相当
🎭
Playwright
ブラウザを自動操作するライブラリ。「ロボットの手」
🌐
Chromium
実際に動くブラウザ本体（Chrome系）。画面に表示される
🔐
.env
銀行のID・パスワードを保存する設定ファイル。Gitに含めない
🗝️
token.json
Google Driveにアクセスするための認証情報。Gitに含めない
📦
googleapis
Google Drive APIを簡単に使えるライブラリ。npmでインストール済み
📂
downloads/
CSVの一時保存場所（PC内）。アップロード後も残る
🐙
GitHub
スクリプトのコードを保存・管理するリポジトリ
